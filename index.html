GymX — Sistema de Gestión de Gimnasio
Plataforma SaaS Full Stack · React 19 + Node.js/Express + MySQL
SaaS
Sistema integral para la administración de gimnasios con diseño Dark & Neon premium. Cubre el ciclo completo de operación: registro de miembros, cobros y suscripciones, punto de venta con control de inventario, check-in con validación en tiempo real y seguimiento de progreso físico.   • Diseño UI/UX premium: glassmorphism + micro-animaciones CSS

02
RhSys — ERP de RRHH y Nóminas
Sistema Empresarial · .NET 10 + Blazor WASM + SQL Server
Enterprise ERP
ERP empresarial de alto nivel para la gestión de Recursos Humanos y cálculo de nóminas, construido sobre Clean Architecture con separación estricta de capas. Implementa patrones de la industria: CQRS con MediatR, Repositorio, DTOs con AutoMapper, Soft Delete con EF Global Query Filters, autenticación JWT con Refresh Tokens y manejo centralizado de excepciones. Frontend SPA desacoplado en Blazor WebAssembly con UI profesional Mobile-First usando MudBlazor.
Patrones Implementados
  • Clean Architecture: Domain → Application → Infrastructure → API
  • CQRS con MediatR: comandos y queries desacoplados
  • JWT + Refresh Token Rotation con HttpInterceptor global
  • Soft Delete vía EF Core Global Query Filters
  • Global Exception Middleware con ProblemDetails estándar
  • AutoMapper + DTOs: sin over-posting ni fuga de datos
Stack .NET 10 C# 13 Blazor WASM MudBlazor SQL Server EF Core MediatR AutoMapper BCrypt.Net Swagger
